# 使用说明（给演示的人看）

## 一、怎么启动

双击 **`启动.bat`**。会自动打开浏览器到 <http://127.0.0.1:8770>。

要**用手机扫码**演示：双击 **`启动_手机扫码.bat`**（电脑和手机连同一个 Wi-Fi）。
第一次启动 Windows 可能弹防火墙提示，选"允许专用网络"。

关掉窗口就等于关掉服务。数据存在 `data/state.json`，删掉它就回到干净的初始状态。

## 二、第一次演示怎么走（照着点就行）

1. **填充候诊队列**（左侧卡片底部）——先放几个人进去，后面解释"为什么别人先进"才真实。
2. **点「① 撕裂样胸背痛 · 58 岁男」**——系统会把"胸口像被刀割一样疼"翻译成"撕裂样胸痛"，
   红旗卡片出现**主动脉夹层**和**心梗**，右边队列里他排到前面，医生接管台立刻收到 P0 工单。
3. **点「③ 停经 45 天」**——这是全场最有说服力的一屏：
   宫外孕预警 + **质控主任卡住"没查 hCG"**，两张工单同时进接管台。
4. **点「⑦ 切菜划伤」→ 再点「模拟扫码上报」**——手机页面点「更痛了」，拉到 10 分，
   分级立刻从 4 级跳到 2 级，队列位次前移。
5. **打开「医生接管台」**（右上角按钮）——看两派意见并列、超时标红、
   降级必须写理由；点「接管该患者」之后，这个人的 Agent 决策就冻结了。

> 演示顺序建议：先"排雷"（②③）证明**能抓住要死人的病**，
> 再"不给高分"（⑦）证明**不会瞎升级**，最后"人来兜底"（接管台）收尾。

## 三、界面上几个容易看漏的点

- **每张 Agent 卡片都可以点开**，里面是它"凭什么这么判"：翻译对照、化验单判读、
  红旗的致命机制与追问清单、质控的 8 项检查、话术的禁忌。
- **红旗卡片里的"追问清单"**是给护士的：不是报警就完了，而是告诉你还该问什么。
- **质控有三种结论**：
  - `建议升级` —— 裁判判低了，自动升级并弹 P0；
  - `带条件放行` —— 级别没判错，但缺关键证据（比如没查 hCG），要人补；
  - `通过` —— 没被推翻。
- **"前面是 1 级心梗"不是编的**：沟通 Agent 读的是真实候诊队列，
  队列里有什么危重患者，话术里就说谁。
- **降级按钮会拦你**：不写理由不让降级。这是故意的。

## 四、常见问题

**Q：ESI 到底是 1–4 级还是 1–5 级？**
标准是 1–5 级。需求里写的 1–4 级是常见简化版。界面默认按标准五级制算，
同时给出四级制的数字；想以四级制为主就运行 `python run.py --esi 4`。

**Q：为什么有的患者判了 2 级而不是 3 级？**
ESI 第 2 步规定：**只要存在高危情况**（比如撕裂样胸痛这种致命病线索）就是 2 级，
跟"需要几项资源"无关。第 3 步只有在第 1、2 步都不成立时才算。

**Q：能不能接大模型？**
能，但不影响主线。规则引擎负责所有承担安全责任的判断；
大模型更适合放在话术改写、病历摘要这种位置。

**Q：端口 8770 被占用？**
`python run.py --port 8780`。

**Q：手机上打不开？**
确认手机和电脑同一个 Wi-Fi、用的是 `启动_手机扫码.bat`、防火墙允许了专用网络。
也可以直接把工作台二维码卡片里的链接复制到手机浏览器。
